# Demo images

Drop **licensed or your own** photos here; `scripts/seed_demo.py` copies them into
`demo/media/` (served on http://localhost:8090) and points the seeded rows at them.
Anything missing is replaced by an obviously-labelled PLACEHOLDER tile -- the seed
never downloads or generates photo-like images. Credits: `CREDITS.md`.

File name = key + one of `.jpg .jpeg .png .webp`. Re-run `scripts/demo_up.sh` after
adding images.
